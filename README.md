# Sleep Tracker

A lightweight browser-based sleep tracking app built with plain HTML, CSS, and JavaScript.

## Features

- Add sleep entries with date, bedtime, wake-up time, quality, and notes.
- Automatically calculates sleep duration, even when bedtime crosses midnight.
- Shows average sleep, best logging streak, and your most recent sleep duration.
- Saves data in browser `localStorage`, so your entries persist on the same device.

## Run locally

Open `index.html` directly in a browser, or serve the folder with a simple static server.
